## 📚 Desafios

### 🦸 1. Classificador de Nível de Herói

Programa que recebe o nome e a quantidade de experiência (XP) de um herói e determina seu nível.

**Conceitos praticados:**

* Variáveis
* Operadores
* Estruturas condicionais
* Laços de repetição
* Entrada e saída de dados

📁 `desafio-classificador-heroi`

---

### 🎮 2. Calculadora de Partidas Rankeadas

Programa que recebe a quantidade de vitórias e derrotas de um jogador, calcula seu saldo de partidas e determina seu nível no ranking.

**Conceitos praticados:**

* Variáveis
* Operadores
* Estruturas condicionais
* Laços de repetição
* Funções
* Parâmetros e retorno de valores

📁 `desafio-partidas-rankeadas`

---

### ⚔️ 3. Escrevendo as Classes de um Jogo

Programa que cria diferentes tipos de heróis utilizando **classes e objetos**. Cada herói possui características como nome, idade e tipo, além de um método responsável por definir seu ataque de acordo com a classe escolhida.

**Conceitos praticados:**

* Classes
* Objetos
* Atributos
* Métodos
* Construtor `__init__`
* Uso de `self`
* Estruturas condicionais
* Funções
* Variáveis
* Laços de repetição
* Entrada e saída de dados
* Formatação com f-strings

📁 `desafio-classes-jogo`
