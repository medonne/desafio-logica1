# 🦸 Classificador de Nível de Herói

Projeto desenvolvido como parte do desafio de **Lógica de Programação da DIO**.

O objetivo do projeto é criar um programa capaz de classificar o nível de um herói de acordo com sua quantidade de experiência (XP).

## 🚀 Como funciona

O programa recebe o **nome do herói** e sua quantidade de **experiência (XP)**.

A partir da quantidade de XP, o herói é classificado em um dos seguintes níveis:

| Experiência (XP)  | Nível      |
| ----------------- | ---------- |
| Menos de 1.000 XP | Ferro      |
| 1.001 a 2.000 XP  | Bronze     |
| 2.001 a 5.000 XP  | Prata      |
| 5.001 a 7.000 XP  | Ouro       |
| 7.001 a 8.000 XP  | Platina    |
| 8.001 a 9.000 XP  | Ascendente |
| 9.001 a 10.000 XP | Imortal    |
| 10.001 XP ou mais | Radiante   |

Ao final, o programa exibe uma mensagem informando o nome do herói e seu nível.

Exemplo:

`O Herói de nome Donne está no nível de Ouro`
